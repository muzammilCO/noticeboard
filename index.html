Connect this app to your GitHub repo so pinned reminders and their schedules sync across every device. Uses a small proxy (see README) so you never paste a long GitHub token here — just a short PIN.

Defaults to noticeboard-sync.yourname.workers.dev — clear the field and save if you ever point this at a different Worker.
The PIN is stored only in this browser's local storage and sent only to your Worker URL. The real GitHub token never leaves the Worker. Set up once per device.
